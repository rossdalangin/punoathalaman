# cPanel Deployment & Installation Guide for Puno at Halaman AI

This guide provides step-by-step instructions for installing and hosting **Puno at Halaman AI** on shared hosting or VPS environments running **cPanel**.

---

## 📋 Prerequisites
- A cPanel hosting account with PHP 8.2 or higher enabled.
- Access to cPanel **File Manager**, **MySQL Database Wizard**, and **phpMyAdmin**.
- (Optional but recommended) cPanel **SSH Access / Terminal** feature.

---

## 📁 Step 1: Uploading Files to cPanel

### Method A: Primary Domain (`public_html`)
1. Compress your project folder into a ZIP archive (`punoathalaman.zip`).
   *Note: Ensure the `vendor` folder generated by running `composer install` locally is included if your hosting provider does not support cPanel Terminal/Composer.*
2. Log in to cPanel and open **File Manager**.
3. Upload `punoathalaman.zip` into your home directory (e.g., `/home/username/punoathalaman`) or `public_html`.
4. Extract the ZIP archive.

### Setting Document Root to `/public`
Because the application entry point is `public/index.php`:
1. In cPanel File Manager, move the contents of `public/` into `public_html/`.
2. Move the non-public directories (`app/`, `config/`, `database/`, `routes/`, `storage/`, `views/`, `vendor/`, `.env`) one level above `public_html` (into `/home/username/`) so private application code is protected from direct public URL access.
3. Edit `public_html/index.php` to adjust relative paths if moved:
   ```php
   require_once __DIR__ . '/../vendor/autoload.php';
   App\Helpers\Config::loadEnv(__DIR__ . '/../.env');
   ```

### Method B: Subdomain or Addon Domain (Recommended)
1. In cPanel, go to **Domains** or **Subdomains**.
2. Create a domain or subdomain (e.g. `puno.yourdomain.com`).
3. Set the **Document Root** directly to the `public/` subfolder:
   `public_html/puno/public` or `punoathalaman/public`.

---

## 🗄️ Step 2: Create MySQL Database & User in cPanel

1. In cPanel, click **MySQL Database Wizard**.
2. **Database Name:** Enter a name (e.g., `username_puno_at_halaman`).
3. **Database User:** Create a user (e.g., `username_puno_user`) and generate a secure password.
4. **Privileges:** Select **ALL PRIVILEGES** and confirm.

---

## 📥 Step 3: Import Database Schema & Seed Data

### Importing `schema.sql` via phpMyAdmin:
1. In cPanel, open **phpMyAdmin**.
2. Select your newly created database (`username_puno_at_halaman`).
3. Click the **Import** tab.
4. Choose `database/schema.sql` from your computer and click **Go**.

### Running Database Seeder:
If SSH Terminal is available in cPanel:
```bash
cd /home/username/public_html
php -r "require 'vendor/autoload.php'; App\Helpers\Config::loadEnv('.env'); Database\Seeders\SeedDatabase::run();"
```
*If Terminal is not available*, you can import seeded SQL data directly or invoke a one-time setup PHP script.

---

## ⚙️ Step 4: Configure `.env` Environment File

Create or edit `.env` in your root application folder with your cPanel database details:

```ini
APP_NAME="Puno at Halaman AI"
APP_ENV=production
APP_URL=https://yourdomain.com
APP_SECRET="your_random_secret_key_here"

# cPanel MySQL Configuration
DB_DRIVER=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=username_puno_at_halaman
DB_USERNAME=username_puno_user
DB_PASSWORD="your_cpanel_db_password"

# AI Provider Configuration (mock, openai, or gemini)
AI_PROVIDER=mock
AI_API_KEY=your_openai_or_gemini_api_key

# Upload & Security Settings
MAX_UPLOAD_SIZE_MB=10
ALLOWED_IMAGE_TYPES=jpg,jpeg,png,webp
STORAGE_PATH=storage/uploads
```

---

## 🔒 Step 5: Directory Permissions & `.htaccess` Security

1. Ensure the `storage/` and `storage/uploads/` directories are writable by PHP (Permissions: `755` or `775`).
2. Create or verify `.htaccess` inside `public_html/` or `public/`:

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^ index.php [L]
</IfModule>
```

---

## ✅ Step 6: Testing the Live Site

Visit your website domain or subdomain in your web browser:
- Home: `https://yourdomain.com`
- Test API endpoint: `https://yourdomain.com/api/plants`

You should see the "Puno at Halaman AI" homepage rendering clearly in both English and Tagalog!
